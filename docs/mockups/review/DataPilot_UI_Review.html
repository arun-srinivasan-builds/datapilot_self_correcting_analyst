Design tokens & consistency notes

--bg #0b1426 · midnight navy--surface #121c30 · graphite--surface-2 #1a2640 · slate--accent #19c3b1 · electric teal--accent-2 #3b82f6 · blue--text #f4f1e8 · ivory--ok #3dd68c · verified--warn #f5b84b · feedback--danger #f0556a · error

Consistent across all screens

  • Same rail, toolbar, pane header and 3 px radius
  • Teal = active/primary, green = verified, amber = feedback/test, red = error/unapproved
  • Every status has a text label or icon, never colour alone
  • Tabular numerals for KPIs, ledgers and tables
  • Cost always reads "Pricing not configured"

Responsive behaviour

  • ≥1400: three-pane layouts, horizontal lanes
  • 1024–1399: narrower side panes
  • 768–1023: single column; vertical lanes (horizontal text was too small)
  • <768: bottom tab bar, 2-up KPI strip, narrow chart variants, tables scroll in-pane

Runtime-honesty rules shown in the design

  • Counter = counted agent messages only (task/events excluded)
  • Repair/feedback edges animate once per real event
  • Human stage is separate from Reviewer approval
  • Fault injection is badged and never shown as natural
  • No timers or progress percentages anywhere
